# Project instructions

- This application was originally written with Qt 5 and is now maintained with Qt 6. For every future change, use current Qt 6 APIs, QML syntax, imports, and best practices in all code that is added or touched.
- Do not introduce deprecated Qt 5 patterns or compatibility workarounds unless they are explicitly required and documented.
- The current development target is Qt 6.12; preserve behavior while modernizing nearby legacy code when it is safely within the scope of the requested change.
